# AgriWater — Smart Agriculture

**Live Frontend Demo:** https://wondrous-jalebi-46e9d6.netlify.app/

AgriWater is a smart agriculture water management system designed to help manage farm records, monitor water resources, and support better crop growth.

## Technologies Used
- Frontend: React.js and Vite
- Backend: Java Spring Boot
- Database: MySQL

## Features
- Farm registration and farm records
- Water monitoring dashboard
- Soil moisture and irrigation statistics
- Water management for better crop growth
